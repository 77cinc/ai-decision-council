# 智囊团·明朝内阁制

> 让 65 位跨越两千年的谋士，成为你的 AI 智囊团。

## 简介

本项目是一套基于 Claude Code skill 系统的**多角色协商决策框架**，灵感来自明朝内阁制。

核心机制：
- **廷推入阁** — 根据议题自动选拔最合适的 5-7 位谋士
- **票拟-批红** — 谋士建言（票拟），用户决策（批红）
- **六科给事中** — 轮值反对派，专挑主流意见的漏洞
- **丝纶簿** — 结构化存档，支持跨会话检索历史议事

## 使用方式

### 前置要求

- [Claude Code](https://docs.anthropic.com/en/docs/claude-code) CLI 或兼容环境
- 将 `.claude/skills/` 目录复制到你的项目根目录下

> **关于谋士 Perspective Skill**：本仓库包含的 65 位谋士 perspective skill 为示例性质。
> 每位谋士的思维框架基于其历史著作和事迹独立提炼，如需使用请自行获取对应的人物 skill 文件。
> 本仓库的核心贡献在于 **council 内阁制协调系统**（廷推→议事→票拟→存档），而非单个人物 skill 的内容。

### 基本用法

```
# 自动廷推（根据议题选谋士）
/council 竞争对手降价了怎么办

# 钦点谋士
/council 是否裁员 孔子,韩非子,德鲁克

# 先调研后廷议
/council-with-research 是否进入新市场

# 查看模式（无参数）
/council
```

### 输出示例

以「竞争对手降价了怎么办」为例，系统自动廷推入阁：

| 角色 | 谋士 | 入选理由 |
|------|------|---------|
| **首辅** | 马云 | 近现代 · 商业实战匹配度 9/10，亲历多次市场博弈 |
| **次辅** | 诸葛亮 | 古代 · 全局谋略匹配度 8/10，守中寓攻 |
| **群辅** | 马斯克 | 当代 · 第一性原理，可重构竞争维度 |
| **给事中** | 韩非子 | 古代 · 制度性质疑，防主流意见盲区 |

议事中各谋士会依次发言、互相回应，最终形成甲策/乙策供主公选择。

### 输出格式

每次议事输出包含：
1. 🏛 廷推入阁名单（含入选理由）
2. 📜 票拟（各谋士发言 + 共识 + 分歧 + 备选方案）
3. ⚠️ 给事中封驳（质疑主流意见）
4. 臣等谨请圣裁（留空批红区由用户决策）
